# AdMob Starter — Godot 4.7

This is a clean Android/iOS AdMob starter using the Poing Studios Godot AdMob plugin v5.0.0.

## What is included
- Banner test ad
- Interstitial test ad
- Rewarded test ad
- Clean Godot 4.7 project
- AdMob Android/iOS test App IDs
- No `.godot` cache
- No plugin demo scene dependencies

## Test IDs
The project uses Google's official test App IDs and ad-unit IDs. Keep the test IDs while developing.

## Android
Open the project in Godot 4.7, make sure the Android export template is installed, then export an APK.

The AdMob plugin may ask Godot to download/install its Android dependencies through its AdMob Manager.

## Before publishing
Replace the test App ID and test ad-unit IDs with your own AdMob IDs and review Google's current policy/consent requirements.
